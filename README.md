# sanghviharshit.github.io

Source for [sanghviharshit.com](https://sanghviharshit.com/) — a single-page personal landing site linking to my GitHub, LinkedIn, and blog.

Built on the [Aerial](https://html5up.net/aerial) template by HTML5 UP (CCA 3.0). Served by GitHub Pages from `master`.

## Local preview

```sh
python3 -m http.server
```

Then open <http://localhost:8000/>.

## Editing styles

`assets/css/main.css` is what's served. The `assets/sass/` sources are optional — if you change them, recompile:

```sh
sass assets/sass/main.scss assets/css/main.css
```

and commit both.
